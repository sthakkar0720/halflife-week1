# halflife-week1
<h1>This is the project for the first week of Hack Club Half Life. I am making a motion controlled digital physical desk pet called Starbie. </h1>
<h2>Starbie is a motion-controlled digital desk pet with a climate sensor, motion sensor, screen, and two buttons for input which will be programmed on the Arduino IDE.</h2>
<h4>I chose to make this project because I was interested to see how  "digital desk pet" would work, so when I saw it in the guide, I chose to  build it. I also want to see how the climate sensor works, as I have never worked with one of those before. Overall, I found the description of this project as very interesting, so I chose to build this instead of designing my own PCB.</h4>
